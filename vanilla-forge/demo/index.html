How to Use

Drop it in · That's it

📦 1. Include the Library

<!-- In your HTML head --> <link rel="stylesheet" href="vd.css" /> <script src="vd.js" defer></script> <!-- Optional: Font Awesome for icons --> <link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.5.0/css/all.min.css" /> <!-- Optional: Raleway font --> <link href="https://fonts.googleapis.com/css2?family=Raleway:wght@300;400;500;600&display=swap" rel="stylesheet" />

🏷️ 2. Use Components

<button class="btn btn-primary">Click Me</button> <span class="badge badge-lime">Active</span> <div class="card">...</div>

⚡ 3. JavaScript API

// Toasts vd.toast('Hello', 'success') vd.toast('Hello', 'cherry') vd.toast('Hello', 'error', 5000) // custom duration // Modal vd.modal.open('modalId') vd.modal.close('modalId') // Dropdown (programmatic) vd.dropdown.toggle('menuId') // Utilities vdSimulateLoad(buttonElement) vdCopy('text to copy')

🎨 4. Customize Theme

/* Override CSS variables in your own stylesheet */ :root { --dc-900: #0A192F; /* change dark chocolate */ --cherry: #FCA5A5; /* change pastel */ --fv-bg: #F0F4F8; /* change background */ }

✅ That's it. No build tools. No dependencies. Just pure vanilla.
