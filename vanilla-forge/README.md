# 🍫 VanillaForge

**French Vanilla + Dark Chocolate · Pastel Rainbow · Tactile Heavy**

> The GUI library that makes Tailwind feel like a bloated mess.

## Why VanillaForge?

| | VanillaForge | Tailwind |
|---|---|---|
| **File Size** | ~10KB | ~200KB+ |
| **Dependencies** | 0 | PostCSS, Node, 20+ deps |
| **Build Step** | None | Required |
| **Learning Curve** | 5 minutes | Weeks |
| **Class Names** | `.btn`, `.card`, `.flex` | `.px-4.py-2.bg-blue-500.hover:bg-blue-600.rounded-lg.transition-colors` |
| **Customization** | CSS Variables (instant) | Config file + rebuild |
| **Tactile Feel** | Mechanical press | Flat garbage |
| **Aesthetic** | French Vanilla + Pastels | Generic blue/gray |

## Features

- 🎨 **7 pastel flavors**: Cherry, Lime, Lemon, Watermelon, Grape, Ocean, Sunset
- ⚡ **Tactile heavy** buttons with mechanical press feedback
- 🧩 **Complete components**: Buttons, Dropdowns, Toasts, Modals, Tabs, Spinners, Badges, Cards, Forms, Tables
- 📐 **~90% Tailwind utility coverage** (flex, grid, spacing, colors, borders, sizing)
- 📦 **~10KB total** · 0 build tools · 0 dependencies
- 🔌 **ES Module + Script tag** support
- 🎯 **Framework agnostic** – works with React, Vue, Svelte, or vanilla
