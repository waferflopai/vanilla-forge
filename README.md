# 🍫 VanillaForge

**French Vanilla + Dark Chocolate · Pastel Rainbow · Tactile & Responsive**

> A beautifully crafted, lightweight GUI library built for joy, speed, and beautiful user interfaces.

VanillaForge is a thoughtfully designed UI library that brings warmth, tactility, and elegance to your web projects. With zero dependencies, a tiny footprint, and a gorgeous pastel palette, it's the perfect companion for developers who appreciate clean design and delightful interactions.

---

## ✨ Features

| Feature | Description |
| :--- | :--- |
| 🎨 **7 Pastel Flavors** | Cherry, Lime, Lemon, Watermelon, Grape, Ocean, Sunset |
| ⚡ **Tactile & Responsive** | Mechanical press feedback · Smooth animations |
| 🧩 **Complete Components** | Buttons, Dropdowns, Toasts, Modals, Tabs, Spinners, Badges, Cards, Forms, Tables |
| 📐 **Flexible Layout System** | Flexbox · Grid · Spacing · Colors · Borders · Sizing |
| 📦 **Lightweight** | ~10KB total · No build tools · Zero dependencies |
| 🔌 **ES Module Ready** | Script tag + ESM support |
| 🎯 **Framework Agnostic** | Works with React, Vue, Svelte, or vanilla HTML |
